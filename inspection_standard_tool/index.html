Case study — FG 3031118

Inspection Standard Tool

A local-first, drag-and-drop tool that builds Inspection Standard Excel files from product photos, scanned PDFs, an Excel template, and the weekly BOM — built for WAHL Vietnam's NPI technicians, no technical steps required.

← Portfolio Open the tool →
This tool is local-first by design. In production it's opened via Launch Inspection Standard Tool.bat, which prepares a browser environment that can read the Excel template and the internal weekly-BOM folder directly from a shared drive — no server, nothing ever leaves the technician's machine. Opened here on GitHub Pages, the drag-and-drop, cropping, and Excel generation work the same way, but BOM auto-suggestions won't populate since the internal weekly-BOM folder isn't available outside the company network.

How it works

1

Load FG + weekly BOM

  • Level 1 requirements cleaned and categorized
  • Existing assignments retained
  • Missing items highlighted immediately
2

Add source evidence

  • Drag photos or scanned PDFs into the asset pool
  • Originals stay unchanged; reusable images can duplicate
  • Grouped by product, color box, master carton, accessories
3

Assign + close BOM gaps

  • Drag evidence into the matching named slot
  • Item name drives auto-tick on category match
  • Missing requirements stay visibly open
4

Generate + review Excel

  • Auto-crop fits images to the template's cell ratio, or crop manually
  • Export blocked until required evidence is complete
  • Review every generated worksheet before release
